# Pemeriksaan web dan admin — 11 November 2026

Lingkungan: Laravel di `http://127.0.0.1:8000`, database Supabase Cloud project `ekzznxsooaqsktlgdlpr` schema `app`, dan Supabase Storage bucket `products`. Ini pemeriksaan server lokal dengan layanan cloud, bukan deployment aplikasi web ke hosting publik.

## Perbaikan dengan TDD

Tes regresi dibuat dan dijalankan sebelum perbaikan. Tes awal gagal pada dua kasus berikut, kemudian lulus setelah perubahan:

1. Kata pencarian `0` diperlakukan sebagai nilai kosong. Perbaikan mencakup query katalog, daftar admin, ekspor Excel, tautan kategori, dan tombol reset filter agar tetap mempertahankan pencarian tersebut.
2. Form ubah password menerima nilai di atas batas bcrypt 72 byte. Password baru sekarang divalidasi sebagai string, dibatasi berdasarkan jumlah byte, dan menolak karakter null sebelum hashing. Tes juga memastikan password lama tidak berubah ketika validasi gagal, password saat ini yang salah ditolak, dan perubahan password valid tetap berhasil.

Sumber regresi: `tests/Feature/AdminRegressionTest.php`.

## Pemeriksaan browser

Menggunakan skill computer-use dengan Chrome. Login dilakukan manual oleh pengguna, kemudian sesi admin diverifikasi lewat browser.

- Daftar admin menampilkan 10 barang demo beserta kategori, harga, stok, dan status publikasi.
- Pencarian `0` menyaring barang dan menghasilkan tautan ekspor dengan `q=0`.
- Tombol Ekspor Excel benar-benar mengunduh `produk-ekatalog.xlsx`; ZIP/XML XLSX dapat dibaca dan baris sesuai filter. Satu barang QA masih ada pada waktu unduhan, sehingga file itu berisi sembilan barang demo yang cocok dan satu barang QA.
- Halaman pengaturan menampilkan field toko dan form ubah password.
- Form tambah barang menampilkan spesifikasi SSD; memilih GPU menggantinya dengan Chipset, VRAM, dan Jenis memori.
- Tombol Keluar mengembalikan browser ke halaman login.

## Pemeriksaan HTTP langsung

24 pemeriksaan berhasil terhadap server yang sama, menggunakan sesi/cookie/CSRF dan akun QA sementara:

- Penolakan akses ekspor sebelum login, login, filter kategori, dan unduhan XLSX dengan dua baris SSD.
- Membuat draft, mengedit barang, dan penolakan publikasi tanpa cover.
- Mengunggah dua foto ke Supabase, membuat record foto, dan mengganti cover di PostgreSQL.
- Perubahan stok 3 menjadi 7; pengulangan request yang sama tidak membuat perubahan atau riwayat ganda.
- Riwayat stok tampil, dan draft tidak bisa diakses dari katalog publik.
- Halaman pengaturan, penolakan data toko tidak valid, serta penolakan password 73 byte tanpa mengubah password.
- Penghapusan dua foto QA, pengarsipan barang QA, penolakan akses barang arsip, logout, dan penolakan akses setelah logout.

Laporan terperinci lokal: `storage/app/private/qa-http-report.json` (diabaikan Git, tanpa password).
